Assistant: The official low-level Python client is **`typesafe-sdk`**, imported as:

```python
from typesafe_sdk import TypeSafeClient
```

Install it with:

```bash
uv add typesafe-sdk
```

There is also a higher-level **`jev`** package:

```bash
uv add jev
```

Use `typesafe-sdk` for direct Jev/System One API access; use `jev` for the decorator-based Python interface.
